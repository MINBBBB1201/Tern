# SMARTFLIGHT Browser-Use & Intelligence Rules

## 1. Real-world Data Verification
- **Dynamic Sourcing**: When APIs lag, use the browser to verify real-time flight availability and pricing from official airline sources.
- **Accuracy Check**: Cross-reference airport codes (IATA/ICAO) to ensure 100% data integrity.

## 2. Visual Validation
- Use the Browser tool to visually inspect the rendered UI across different viewports, ensuring the Skyscanner-style density is maintained.
